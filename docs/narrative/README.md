# 剧情设计

当前模板没有预设世界观、人物或剧情。需要叙事内容时，在这里记录供开发者和 Codex 理解的设计，并按实际内容建立文档：

| 文档 | 内容 |
|---|---|
| `world.md` | 世界背景、基本规则与重要地点 |
| `characters.md` | 人物身份、动机、关系与角色变化 |
| `story.md` | 主线、章节、关键事件与结局 |

内容较少时可以先写一份剧情文档，出现足够多的人物或章节后再拆分。每个决定保留一个主要记录位置，其他文档通过链接引用。

## 设计与运行数据

这里的 Markdown 是设计资料，游戏不直接读取。需要执行的对话、任务、条件和事件数据放在 `game/` 对应功能目录，例如 `game/dialogue/` 或 `game/quests/`，与其脚本和专用资源一起维护。

实现剧情时，通过明确的人物、事件或章节名称对应设计与运行数据，避免把游戏行为绑定到 Markdown 的标题、段落顺序或排版。新增文档后更新上级 [文档索引](../README.md)。
