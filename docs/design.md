# 游戏设计

当前内容是模板的示例玩法，用于验证开发工具和最小游戏循环。复制模板制作新游戏时，将本文更新为新游戏的目标和范围。

## 核心循环

玩家在单个俯视角场地内移动，绕过墙体和障碍，收集五个晶体。HUD 显示收集进度；全部收集后显示完成反馈，玩家可以重新开始。

## 当前范围

- 单个场景、一个可控角色、五个收集物和固定障碍。
- 使用几何占位图形，无需下载素材或调用外部服务。
- 支持键盘和手柄移动，提供键盘、手柄和按钮三种重开入口。
- 场景和 UI 保存在 `.tscn` 中，可直接在 Godot 编辑器查看。

示例没有敌人、战斗、背包、存档或剧情。扩展时从具体玩法需要出发，先完成一个可玩的循环。

## 操作

| 操作 | 输入映射 | 键盘 | 手柄 |
|---|---|---|---|
| 移动 | `move_left/right/up/down` | WASD 或方向键 | 左摇杆 |
| 重开 | `restart` | R 或点击“重新开始” | Y |

## 内容位置

- `game/main/`：关卡组合、HUD、得分和重开。
- `game/characters/player/`：角色场景和移动。
- `game/objects/pickup/`：收集物场景、动画和收集信号。
- `tests/test_game.gd`：核心行为验证。

角色参数保存在对应脚本的导出属性和场景中；收集目标由主场景中的收集物数量决定。

## 验收

1. 场景可以启动，初始进度为 `0 / 5`。
2. 玩家响应移动输入，不能穿过场地边界。
3. 接触晶体后，进度增加且该晶体从场景移除。
4. 收集全部晶体后，进度为 `5 / 5` 并显示完成反馈。
5. 重开后恢复玩家位置、全部晶体和初始进度。
6. 中文 HUD、角色、障碍和晶体在实际运行画面中可见。

行为验证使用 `python3 tools/dev.py check`；画面通过运行游戏并截图检查。
