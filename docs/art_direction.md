# 视觉约定

当前示例采用俯视角 2D 几何占位画面，目的是让移动、碰撞和收集反馈容易观察。它不代表新游戏必须采用的正式美术风格。

## 当前画面

- 基准视口为 960 × 540，使用 Compatibility 渲染器。
- 深色背景与场地，青绿色角色，金色收集物，灰蓝色墙体和障碍。
- 收集物有轻微缩放动画，HUD 显示中文说明、进度和重开按钮。
- 图形由场景中的 `Polygon2D` 构成，未使用外部素材包。
- 默认纹理过滤为最近邻，后续接入像素素材时可保持像素边缘清晰。

## 接入正式素材

开始制作时先确定目标画风、角色尺寸、场景比例和动画需求，再替换占位图形。保持素材视觉大小与碰撞形状一致；新增 UI 布局仍保存到 `.tscn` 中。

运行时素材集中放在 `assets/`，按角色、环境、UI、音频和字体等实际用途分类。制作原稿放在 `assets/source/`，游戏使用的导出文件放在对应素材目录；原稿目录不参与 Godot 导入。外部素材的信息登记到 [素材记录](../assets/credits.md)。

修改画面后运行游戏，检查中文显示、UI 裁切、角色与碰撞边界、素材比例和动画反馈。可通过 MCP 截图，也可使用 `python3 tools/dev.py capture`。
